WINGO AI PRO - Android Studio Project

ਇਹ APK ਦਾ source project ਹੈ, compiled APK ਨਹੀਂ।

APK ਬਣਾਉਣ ਲਈ:
1. ਕੰਪਿਊਟਰ 'ਤੇ Android Studio ਇੰਸਟਾਲ ਕਰੋ।
2. Android Studio ਵਿੱਚ ਇਸ ZIP ਨੂੰ Extract ਕਰਕੇ 'Open' ਕਰੋ।
3. Gradle Sync ਪੂਰਾ ਹੋਣ ਦਿਓ।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) ਚੁਣੋ।
5. APK app/build/outputs/apk/debug/app-debug.apk ਵਿੱਚ ਮਿਲੇਗੀ।
6. APK ਫੋਨ ਵਿੱਚ ਭੇਜ ਕੇ install ਕਰੋ।

ਮੌਜੂਦਾ ਫੀਚਰ:
- Dark black + green interface
- 0-9 ਨੰਬਰ ਹੱਥੀਂ ਜੋੜਨਾ
- BIG (5-9) / SMALL (0-4) classification
- Local history ਅਤੇ historical frequency

Automatic result fetching:
ਦਿੱਤੇ ਗਏ game domain ਲਈ verified, authorized API endpoint ਜਾਂ official integration details ਨਹੀਂ ਮਿਲੀਆਂ। ਇਸ ਲਈ ਇਸ project ਵਿੱਚ website scraping ਜਾਂ login/password capture ਨਹੀਂ ਹੈ। Official API ਮਿਲਣ 'ਤੇ ਹੀ safe automatic sync ਜੋੜਿਆ ਜਾ ਸਕਦਾ ਹੈ।

ਇਹ app betting advice ਨਹੀਂ ਦਿੰਦੀ। Random game outcomes ਦੀ prediction ਜਾਂ 80% accuracy ਦੀ ਗਾਰੰਟੀ ਨਹੀਂ।

ਵਿਕਲਪ: GitHub ਰਾਹੀਂ APK build
1. ਇਸ project ਨੂੰ ਆਪਣੇ GitHub account ਵਿੱਚ ਨਵੀਂ repository ਵਜੋਂ upload ਕਰੋ।
2. GitHub ਵਿੱਚ Actions tab ਖੋਲ੍ਹੋ।
3. 'Build Wingo AI Pro APK' workflow ਚੁਣ ਕੇ Run workflow ਦਬਾਓ (ਜਾਂ main branch ਵਿੱਚ push ਕਰੋ)।
4. Build ਸਫਲ ਹੋਣ 'ਤੇ workflow run ਦੇ Artifacts ਹਿੱਸੇ ਵਿੱਚ 'Wingo-AI-Pro-debug-apk' ZIP ਮਿਲੇਗੀ।
5. ZIP download ਕਰਕੇ extract ਕਰੋ; app-debug.apk ਨੂੰ Android phone ਵਿੱਚ install ਕਰੋ।

ਨੋਟ: GitHub account ਅਤੇ internet ਦੀ ਲੋੜ ਹੈ। ਇਹ debug APK ਹੋਵੇਗੀ, Play Store release-signed APK ਨਹੀਂ।
